# add game engine

## Objectif
les actions sont actuellement quasi instantané, il faudrait que le jeu soit mieux cadencé. Je veux un moteur de jeu qui prendra en compte les évolutions futurs.

# Contexte

J'aimerais qu'il y ai un léger délais entre chaque action du joueur, que ca soit la pose d'une bombe ou un déplacement.
J'aimerais un moteur de jeu qui implemente cela, je te laisse définir quelle frequence de jeu est la plus adapté. L'idée est également de prévoir ce moteur pour de futures évolutions comme le mode multijoueur ou d'autres personnages adversaires pilotés par un ordinateur.

## Contraintes
Tu dois implementer ce nouvel ajout, je veux un jeu de test permettant de prouver son bon fonctionnement et son maintien. 

## Critère de succès
Le projet actuel compile, l'ensemble des tests passent.

## Hors scope
les fonctionnalités de multijoueur et d'ordinateur ne sont pas attendu.
