# add multiplayer

## Objectif

L'objectif de cette tâche est d'implementé un mode multijoueur de 2 à 4 joueurs.

## Contexte / fichiers concernés

Je souhaite avoir un mode multijoueur avec un joueur hôte et de 1 à 3 joueurs pouvant rejoindre cette session.
Chaque joueur aura sa device, ils doivent tous être connecté sur le même réseau wifi.
Je souhaite aussi faire une page de salle d'attente entre l'hote et les clients.
Indique-moi les limitations techniques que tu rencontres.
Réalise le jeu de test associé.

## Contraintes

Travaille sur une nouvelle branche qui part du master.
rédige une documentation complète sur comment tu as mis en place le mode multijoueur.
Je veux un droit de regard sur les choix techniques que tu entreprends.

## Critère de succès

Le projet doit compiler, les tests passent.
